# Prints reais da aplicação

Para concluir a entrega, rode a aplicação no servidor da sala (porta 8080 ou 8081) e salve aqui:

- `dashboard-desktop.png` — crachá e métricas no navegador;
- `projetos.png` — grade de projetos e filtro funcionando;
- `dashboard-mobile.png` — layout responsivo (opcional).

A captura exigida deve ser da aplicação **realmente executada**. Não foram incluídas imagens simuladas como prova de execução.

Depois de salvar as imagens, o `README.md` da raiz já estará pronto para exibi-las.
